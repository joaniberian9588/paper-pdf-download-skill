This repository contains original orchestration and verification code. It does not bundle browser binaries, MinerU models, InstSci, or downloaded papers.

[CloakBrowser](https://github.com/CloakHQ/CloakBrowser) is an optional runtime dependency. Its Python source is distributed under the MIT License; its Chromium binary is governed by a separate binary license. Users install it independently and should review both upstream licenses.

## MinerU

[MinerU](https://github.com/opendatalab/MinerU) is an optional external converter. It is not redistributed here. Current MinerU releases and models are governed by the licenses published in the MinerU repository. The optional `mineru-open-api` route sends documents to a third-party service and is disabled unless the user explicitly supplies `--mode api --allow-upload`.

## InstSci

[InstSci](https://github.com/Rimagination/instsci) is an MIT-licensed independent project. It is not a dependency and its Skill is not included here. Its public work informed the breadth of the publisher checklist and the importance of layered result classification and main-PDF verification. Users who prefer visible institutional workflows, OA-first search, or an MCP server should evaluate InstSci directly.
